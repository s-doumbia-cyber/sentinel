# Demo scenario (synthetic, tagged DEMO)

Generated by `npm run demo:data` (`scripts/demo-data.mjs`). The script is deterministic
(fixed seed) and touches no database: it only writes the two files below.

| File | Content |
|---|---|
| `demo-scenario-flows.csv` | 585 **synthetic** flows in the CICIDS2017 column layout, 2026-10-19 09:00–09:30 UTC: benign office traffic (SMB, DNS, HTTPS, an admin SSH session), then a port scan from `10.0.0.66` against `10.0.0.20` at 09:10 (180 ports), then an SSH brute force from the same host at 09:14 (45 short sessions). |
| `demo-identity.csv` | Synthetic DHCP and authentication records for the same addresses (`SRV-FILES-01`, `WS-031`, `UNMANAGED-66`, the account `demo.user31`). |

## What it demonstrates

- The starter rules `R-PORTSCAN-01` and `R-BRUTEFORCE-SSH-01` fire on the attack flows.
- The two alerts share a source within 15 minutes, so Sentinel groups them into one
  correlated incident (Discovery → Credential access) and labels the grouping a hypothesis.
- Attribution for `10.0.0.66` comes from a DHCP lease (medium confidence: DHCP says which
  device held the address, not who used it). Addresses with no record stay "unknown".
- Asset pages show observed services and a low-confidence device estimate.

## What it is not

Synthetic traffic written to exercise the product, not a capture of a real network and not
a benchmark. Feature values are plausible but simplified (many features are 0), so model
verdicts on these flows say little about model quality. Labels (`BENIGN`, `PortScan`,
`SSH-Patator`) are ground truth for evaluation only; they never become verdicts.

## Using it (development database only)

```powershell
npm run demo:data
npm run import:csv -- --org <your-org-slug> --demo "data/demo/demo-scenario-flows.csv"
```

The `--demo` flag tags every flow `DEMO`. A command-line import does not trigger detection:
open **Rules** and click "Run now" (uploads from the Datasets page trigger it automatically).
Then import `demo-identity.csv` from **Identity sources**.
Use an organisation created for the demo: imported flows and identity records can be
removed from the Datasets and Identity sources pages.
